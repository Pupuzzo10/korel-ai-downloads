## Aggiornamenti

- I miglioramenti dell'interfaccia e di Korel Coder arrivano dal servizio online.
- Dalla 0.3.0, gli aggiornamenti nativi dell'app vengono controllati tramite GitHub Releases. L'app scarica l'aggiornamento e chiede conferma prima del riavvio.
- Chi usa la 0.1.0 o la 0.2.0 deve installare manualmente una volta la 0.3.0.

**Nota di sicurezza:** l'installer beta non è ancora firmato digitalmente. Windows SmartScreen può segnalare un editore non riconosciuto. Utilizza esclusivamente i file di questa repository e non disattivare antivirus o protezioni di Windows. Il file `SHA256SUMS.txt` pubblicato con ogni release permette di verificare l'integrità del download.
